# Docs

Notes behind the SWEG layouts. Nothing here is part of a layout folder or a
Herdr install.

## Contents

| Path | Status | What it is |
| ---- | ------ | ---------- |
| [plans/](plans/) | Historical | Work plans kept as the decision record. [20261103-setup-layout.md](plans/20261103-setup-layout.md) is the original build plan for the `sweg` layout (2026-11-03). Status: historical, replaced by the current layout folders. |
| [research/](research/) | Archive | Research notes and decision inputs: px0 capabilities, workspace mode tradeoffs, runtime cost audit, and screenshots. See [research/README.md](research/README.md) for the document index and the historical naming note. |

These notes describe the repo at the time they were written. The tree, the
layout names and the mod names can differ from the current ones. The
[research index](research/README.md) lists the old names and what they map to
now.
